# VFX Style

One anime look for every effect texture. Generated by `scripts/blender/vfx_textures.py`.

## Rules

- **Crisp shapes, soft glow.** Hard anti-aliased silhouettes (crescents, spikes, rings) wrapped in a soft exponential glow falloff.
- **White cores, tint in Roblox.** RGB is white to near-white (0.8–1.0). Element colour comes from the `Color` property of the ParticleEmitter, Beam or Decal. Shading is light grey, never coloured.
- **Real alpha.** Transparent backgrounds only, never black. Invisible pixels stay white so filtering never adds a dark fringe. Use `LightEmission` for an additive look.
- **Readable at distance.** Bold silhouettes and few fine details. The shape still reads at 32 px.
- **Sizes.** 256 px for small sprites (glow, sparks), 512 px for everything else, 1024 px only for 4x4 flipbooks (256 px frames).
- **Flipbooks.** 4x4, frames run left to right, top to bottom. Fire loops. Smoke and explosion play once and end empty.
- **Names.** `vfx_<family>_<variant>.png`, stable across revisions.

## Families

| Family | Textures | Use |
|---|---|---|
| slash | thin, wide, double | Melee arcs. Bright leading edge, faded tail. |
| glow | soft, hard_core | Generic light, auras, cores. |
| ring | thin, thick, segmented | Shockwaves, AoE telegraphs. |
| spark | streak, star | Hit sparks, twinkles. |
| smoke | puff, flipbook | Dust, aftermath. Two-tone cel shading. |
| explosion | flipbook | Flash, then fireball, then smoke. |
| fire | flipbook | Burning, fire abilities (loop). |
| lightning | strip | Beam texture, tiles along U. |
| energy | swirl, orb | Charge-ups, projectiles. |
| ground | crack, scorch | Floor decals. Tint scorch dark grey for soot. |
| impact | starburst | Hit confirm. |

## Into the game

1. `lune run scripts/vfx-upload <userId>` (with `ROBLOX_API_KEY` set) uploads new PNGs as Decals and writes `assets/vfx/ids.json` (name -> image id) and `assets/vfx/decals.json`.
2. `lune run scripts/vfx-apply` maps them to roles and writes `src/shared/VfxPicks.luau`.
3. Traits (flipbooks, scale, tiling) and per-usage `on` switches are in `src/shared/VfxConfig.luau`.
